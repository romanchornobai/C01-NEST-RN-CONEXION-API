--- ACTIVAR CORS EN main.ts (OBLIGATORIO PARA CONECTAR DESDE EL MOVIL) ---
Ubicacion: src/main.ts

import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.enableCors(); // <--- PERMITE PETICIONES DESDE REACT NATIVE
  await app.listen(3000);
}
bootstrap();


--- SEPARACION CONTROLLER Y SERVICE ---
- Controller: Gestiona la ruta HTTP (@Get, @Post, @Patch), recibe parámetros y delega.
- Service: Gestiona los datos (arrays en memoria), filtros y lógica de negocio.

--- INYECCION DE DEPENDENCIAS EN EL CONTROLLER ---
constructor(private readonly productosService: ProductosService) {}


--- DECORADORES Y METODOS HTTP ---

1) GET SIMPLE (LISTAR TODO)
Controller:
  @Get()
  findAll() {
    return this.servicio.findAll();
  }

2) GET CON PARAMETRO DE RUTA (BUSCAR POR ID)
Ruta: GET /recurso/:id
Controller:
  @Get(':id')
  findOne(@Param('id') id: string) {
    return this.servicio.findOne(Number(id)); // Convertir a Number si el ID es numérico
  }
Service:
  findOne(id: number) {
    return this.lista.find(item => item.id === id);
  }

3) GET CON QUERY PARAMS (FILTRAR)
Ruta: GET /recurso?genero=accion
Controller:
  @Get()
  findAll(@Query('genero') genero?: string) {
    if (genero) {
      return this.servicio.findByGenero(genero);
    }
    return this.servicio.findAll();
  }
Service:
  findByGenero(genero: string) {
    return this.lista.filter(item => item.genero.toLowerCase() === genero.toLowerCase());
  }

4) PATCH (MODIFICAR PARTE DE UN RECURSO, EJ: LIKES)
Ruta: PATCH /recurso/:id/like
Controller:
  @Patch(':id/like')
  darLike(@Param('id') id: string) {
    return this.servicio.incrementarLike(Number(id));
  }
Service:
  incrementarLike(id: number) {
    const item = this.lista.find(x => x.id === id);
    if (item) {
      item.likes = (item.likes || 0) + 1;
    }
    return item;
  }

5) POST (CREAR NUEVO RECURSO CON CUERPO JSON)
Ruta: POST /recurso
Controller:
  @Post()
  crear(@Body() body: { nombre: string; precio: number }) {
    return this.servicio.crear(body);
  }
Service:
  crear(dto: { nombre: string; precio: number }) {
    const nuevo = {
      id: this.lista.length + 1,
      ...dto
    };
    this.lista.push(nuevo);
    return nuevo;
  }

6. ERRORES TIPICOS EN EXAMEN Y COMO RESOLVERLOS
================================================================================

1. ERROR: "Network request failed" o "TypeError: Failed to fetch"
   - Causa 1: Olvidaste app.enableCors() en main.ts del backend.
   - Causa 2: Pusiste "http://localhost:3000" en el frontend en vez de tu IP local.
   - Causa 3: El backend no está corriendo (ejecuta npm run start:dev).
   - Causa 4: Móvil y PC están en redes Wi-Fi diferentes.

2. ERROR: El backend siempre devuelve undefined o no encuentra por ID
   - Causa: @Param('id') id: string llega como TEXTO. Si tu array usa IDs numéricos (1, 2, 3), id === item.id dará false ('1' !== 1).
   - Solución: Number(id) o parseInt(id).

3. ERROR: Git no detecta archivos dentro de frontend o backend
   - Causa: Se crearon carpetas .git dentro de las subcarpetas.
   - Solución: En Git Bash ejecuta:
     rm -rf backend/.git
     rm -rf frontend/.git
     git add .

4. ERROR: FlatList no renderiza nada o da error de clave
   - Causa: Falta keyExtractor o no devuelve un string.
   - Solución: keyExtractor={(item) => item.id.toString()}
